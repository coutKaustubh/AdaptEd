# AdaptEd

AdaptEd is a Vercel-ready React + TypeScript prototype for adaptive learning and concept-level intervention.

## Run locally

```bash
npm install
npm run dev
```

## Demo access

- Student: `aarav@adapted.demo` / any password
- Teacher: `priya@adapted.demo` / any password

The prototype uses synthetic demo data and persists login state, mastery changes, attempts and view selection in `localStorage`.

## Deploy to Vercel

Import this repository into Vercel. The defaults are sufficient:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

No environment variables or backend services are required for the demo.
